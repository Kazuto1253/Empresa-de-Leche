# Evidencias

Este directorio recibirá únicamente evidencia real de ejecución del proyecto.

## Organización sugerida

```text
docs/evidencias/
  semana-01/
  semana-02/
  semana-03/
  semana-04/
```

Cada archivo debe usar un nombre descriptivo, por ejemplo:

```text
s4-android-navegacion-principal.png
s4-desktop-tema-oscuro.png
rf06-pruebas-limites-cantidad.png
```

## Reglas

- No usar imágenes de otro proyecto o de ejemplos del docente.
- No afirmar que una prueba fue ejecutada sin salida verificable.
- Ocultar contraseñas, tokens, DNI reales, teléfonos y otros datos personales.
- Relacionar la evidencia con una semana, RF, caso de prueba o Pull Request.
- Evitar binarios repetidos o capturas que no aporten verificación.
