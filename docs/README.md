## Regla de evidencia

- **Confirmado:** respaldado por las reuniones o por una decisión académica explícita.
- **Inferido:** necesario para mantener coherencia, pero debe revisarse.
- **Propuesto:** decisión técnica o académica del equipo.
- **Pendiente de validación:** no debe automatizarse como regla definitiva.
